# Connect to the Coda MCP 

The Coda MCP (Model Context Protocol) is a connection layer that enables AI clients - like Cursor, Claude, etc. - to read and write to your Coda docs using plain-language prompts. Instead of clicking through the Coda UI, you describe what you want in the chat window of your chosen client, and the AI carries it out directly in your doc. Think of it as giving an AI agent the same access to your Coda workspace that you have, and letting it act on your behalf based on your instructions.

The following article will walk you through the steps of connecting your preferred AI tool to the Coda MCP. Once you’ve connected, you can check out this article for some helpful guidance and examples on using the Coda MCP.

ℹ️ The Coda MCP is in beta. Behavior and available tools are subject to change.

# Connect ChatGPT with Coda MCP

Follow the steps below to connect ChatGPT with Coda MCP:

1. Within ChatGPT, click into the Apps tab of the left panel
2. Enter "Coda" in the search bar
3. Select Coda from the search results, then click Connect

1. Note: If you see Disabled by admin instead of Connect, this likely indicates that the admin of your account has disabled connecting to new apps. We suggest contacting your admin and requesting they enable the Coda app for you or your org. Refer to this documentation to learn more.

6. Once authentication has been completed, you'll be redirected back to ChatGTP and should see a Coda is now connected confirmation.

You should now be successfully connected to the Coda MCP and can start using it within your chats.

Tip: If you would like to give ChatGPT more context when working with Coda, look for the Reference memories and chats setting during the connection process (right below the Sign in with Coda button). This setting is toggled off by default, but you can toggle it on if desired. And if you've already connected to Coda and want to change this setting retroactively, just click on your account name in the lower-left > Settings > Apps > Coda app > toggle on/off the Reference memories and chats option.

## Resolve Node issues when connecting to Claude desktop

Download the latest version of Node.js

Claude Desktop requires a tool called Node.js to run the Coda MCP connection. To install the latest version of Node, follow these steps:

1. Hit Cmd+Space → Terminal to open Terminal.
2. In Terminal, type or paste the following command:

```
/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

3. Hit Enter.
4. Terminal will ask for your Mac login password. When you type it, nothing will appear on screen — no dots, no asterisks, nothing. This is completely normal! Just type your password carefully and hit Enter.
5. The installation may take a few minutes. Make sure to pay attention to Homebrew's instructions for next steps. You'll likely need to run three individual commands in your terminal to add Homebrew to your PATH — two start with `echo` and one starts with `eval`.
6. Wait until you see the regular prompt again (ending with `%` or `$`). Then install Node.js by pasting the following command:

```
brew install node
```

7. Hit Enter.
8. Verify everything is installed correctly by pasting the following command:

```
npx --version
```

9. Hit Enter.
10. If you see a version number (like `10.8.2`), you're good to move on. If it says `command not found`, try closing and reopening Terminal, then run `npx --version` again.

If Node is installed but you’re still running into errors...

For instance, you might be seeing "File is not defined," "Cannot find module 'node:path,'" or "Unsupported engine" errors when connecting the Coda MCP on Claude Desktop. This can happen if you have multiple Node.js versions installed and your system is defaulting to the wrong one. To resolve this, follow the steps below:

Step 1: Find your Node 20 path

1. Hit Cmd+Space → Terminal to open Terminal.
2. In Terminal, type or paste the following command:

```auto
nvm which 20
```

3. Hit Enter.

This should print a path like `/Users/yourname/.nvm/versions/node/v20.x.x/bin/node`. Copy everything up to and including `/bin/` — you'll need it in the next step.

If this command says `N/A` or fails, install Node 20 first:

```auto
nvm install 20
```

Then run `nvm which 20` again.

 

Step 2: Connect to the Coda MCP via the Claude UI

1. Follow the steps in the " Connect Claude Chat & Cowork to Coda MCP" section of this article. 

Step 3: Clear the npm cache

1. Hit Cmd+Space → Terminal to open Terminal.
2. In Terminal, type or paste the following command:

```auto
rm -rf ~/.npm/_npx
```

3. Hit Enter. 

Step 4: Restart Claude Desktop

1. Fully quit and reopen Claude Desktop.
2. The MCP Server should now connect successfully. 

Windows users: The steps are the same, with a few differences:

- To find your Node 20 path, run `nvm which 20` in Command Prompt.
- Open Command Prompt by hitting Win+R, typing `cmd`, and hitting Enter.
- The path will look like `C:\Users\yourname\AppData\Roaming\nvm\v20.x.x`.
- When updating your config, set `"command"` to that path followed by `npx.cmd`, and update the new `"PATH"` to use that same folder with semicolons instead of colons.
- To clear the npm cache, run `rmdir /s /q %LOCALAPPDATA%\npm-cache_npx`.

# Connect Claude Code with Coda MCP

To connect Claude Code to the Coda MCP, follow these steps:

1. To start, open a fresh terminal window and run the following block:

```
claude mcp add --transport http Coda https://coda.io/apis/mcp
```

2. Once the above has run, type `Claude` into your terminal and hit Enter 
3. Then type `/mcp` into the terminal and hit Enter again.
4. You should now see a notice that Coda MCP needs authentication. Click Enter and select Authenticate.
5. This will open a browser window where you'll be asked to allow Claude Code access to Coda. You'll also see that the redirect URL is `localhost`, which is expected based on how Claude handles OAuth. Follow the prompts to accept and proceed. You should then see an Authentication Successful confirmation.
6. To confirm connection to the Coda MCP, return to your terminal window and enter the following:

```
Are you connected to the Coda MCP?
```

If successful, you’ll see a success message with Coda MCP tools. You can now start building in Coda using Claude Code!

# Connect Copilot Studio with Coda MCP

To connect Copilot Studio with the Coda MCP, you will need to authenticate via Personal Access Tokens from your Coda account. Follow the steps below to learn more:

1. First, you’ll need to generate a personal access token from your Coda account page. You can click here (or scroll to the API settings section of your account page, then click Generate API token). Give your token a memorable name, ensure that the restriction type is MCP, and choose the type of access. Then click the Generate API token button to create. Once created, click the Copy token button to copy it to your clipboard.

![generate token for coda mcp.gif](https://staging.codahosted.io/docs/ZO_Xf5cp9n/blobs/bl-vp697CmOpF/e77404b9932980d01f466c4726f7d634ef24770b2dd1950f857e216cb530e5f1a2cd95a73dde4f85841320960bd1396fa1177a8d58ff5137e6084e210d58ff9073eaf87262f3fa6a85efc637119417fd4ad7dfe88d479cf4296a719cf7dc37b44a650e24)
2. Next, within Copilot Studio, open the agent you want to connect to the MCP.
3. From the menu across the top of the agent page, select Tools, then click the + Add a tool button.
4. Within the Create new options, select Model Context Protocol.
5. Enter the following info:

1. Server name and Server Description: fill these in as you see fit (for instance "Coda MCP" and "Coda MCP to read and write to docs"
2. Server URL: https://coda.io/apis/mcp
3. Authorization: Select the API Key option. Then for the Type choose Header, and for the Header name enter `Authorization`
6. Once all the above info has been entered, hit Create.
7. You'll then see the newly added tool, but you'll notice it's not yet connected. Click on Not connected and select Create new connection.
8. In the hidden field, enter the following string: `Bearer Your-Coda-Auth-Token` - making sure to replace Your-Coda-Auth-Token with the token you generated in step 1.

1. For instance, `Bearer 1bxxxxxx-xxxx-xxxx-xxxx-xxxxxxxxxxxx`
9. Hit Create button to finalize the connection.

# FAQs

Can I connect Coda MCP to other AI tools not listed in this article?

You should be able to connect the Coda MCP to any AI client that supports creating custom MCP connections. In most cases, you will need to use Personal Access Tokens to complete the connection.

To acquire these access tokens from Coda, you can click here (or scroll to the API settings section of your account page, then click Generate API token). Give your token a memorable name, ensure that the restriction type is MCP, and choose the type of access. Then click the Generate API token button to create. Once created, click the Copy token button to copy it to your clipboard.

Do I have to be a Doc Maker to connect to the Coda MCP?

No - you do not have to be a Doc Maker to connect to the Coda MCP. Anyone can connect to the Coda MCP, but what you can do from there does depend on your role in Coda.

 Doc Makers on paid Coda plans will have access to the full Coda MCP experience, including all of the available tools and endpoints.

 

Doc Makers on free plans can utilize a “free taste” of the Coda MCP (30 requests per week, with a max of 60 requests per month). During this “free taste,” you can utilize all of the tools of the MCP.

 

Editors also have access to a “free taste” of the Coda MCP (30 requests per week, with a max of 60 requests per month). However, they are limited to only the “read” type tools and actions. In other words, editors will not be able to use the MCP to update or add content, or to take other Doc Maker actions.

 

Can I configure Coda MCP as a custom connector in Claude, so the rest of my organization can easily connect? 

Yes - if you are on a Team or Enterprise plan in Claude, an Owner or Primary Owner can configure Coda MCP as a custom connector on behalf of your org. Once this is done, organization members can easily find the Coda MCP in their available connectors and will be able to connect in a few short clicks.

To complete this configuration on behalf of your organization, follow these steps:

1. Ensure you're logged into Claude as an Owner or Primary Owner
2. Open Organization settings
3. Click into the Connectors tab
4. In the upper-right, click the Add button, hover over the Custom option, then select Web
5. Next, enter the following URL in the appropriate field: https://coda.io/apis/mcp
6. Finally, click Add

Now, when members of your org navigate to the Connectors section of their Claude settings, they will see Coda as an available connector (with a custom label). They'll just need to click the Connect button, then follow the prompts to authenticate.

Read more about configuring and connecting to custom connectors in Claude here.

Why am I getting a 401 error when trying to use my auth token to connect?

You may see this error when the auth token has the incorrect restriction type. To resolve this, we suggest creating a new auth token via your Coda account settings, this time ensuring that you select MCP for the restriction type. Then attempt the connection again using this new token.

What auth scopes are used when connecting to the Coda MCP?

When connecting the Coda MCP via OAuth 2 (as with ChatGPT, Claude, and Cursor) the auth scope will automatically be set to read and write.

When connecting via Personal Access Tokens (as described for Google Antigravity and OpenAI Codex), you have the option to choose between three scopes: read only, write only, read and write.

 

Therefore, if you wish to limit the scope to read only or write only, we recommend connecting via Personal Access Tokens instead of OAuth 2.

How do I submit bugs or feedback for the MCP?

Please submit any bugs or feedback via this form. Thank you in advance!
