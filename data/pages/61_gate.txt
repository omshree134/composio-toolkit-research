# Technology Partners

Bring your solution into the workflows where developers build, secure, and ship software.

## Build with GitHub

Create integrations across the GitHub platform and bring your product into the workflows developers use every day.

### Extend your product

Connect your solution to GitHub through apps, GitHub Actions, APIs, security integrations, and MCP servers.

### Reach more developers

Make your integration discoverable to GitHub's global developer community and help shared customers build, secure, and ship software.

## How to qualify

### What we look for in a GitHub Technology Partner Program applicant

![copilot head and cubes](https://images.ctfassets.net/8aevphvgewt8/6ozbNHKa6rn7zyJm4wi7Wi/63ee52935364116ce978fa704b0a1b71/harness-wallpaper.webp?fm=webp)

What we look for in a GitHub Technology Partner Program applicant

Is an established technology company with a commercially available product.

Provides or plans to provide a GitHub integration that delivers clear value to shared customers.

Has the technical resources to build, secure, support, and maintain the integration.

Integration paths

## Choose the integration model that fits your product and the experience you want to create.

### GitHub Apps and Marketplace

Build a GitHub App and make your solution discoverable through GitHub Marketplace.

### GitHub Actions

Automate build, test, security, deployment, and operational tasks in customer repositories.

### MCP

List your MCP server in the GitHub MCP Registry and make it available across supported GitHub experiences.

### GitHub Advanced Security

Connect your solution to code scanning, vulnerability management, security information and event management (SIEM), and security reporting workflows.

### Secret scanning

Help prevent credential leaks by joining GitHub's secret scanning partner program.
