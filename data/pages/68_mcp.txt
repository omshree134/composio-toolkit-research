## FAQ

### What is an MCP Server?

An MCP server implements the Model Context Protocol (MCP), introduced by Anthropic in November 2024. MCP is a standard that defines how LLM-based applications connect with diverse data sources and systems, especially for agentic use cases. It enables interoperability and modularity in complex AI ecosystems, making deployment easier, more flexible, and scalable.

### How is the MongoDB MCP Server used?

The MongoDB MCP Server connects any MongoDB deployment (Atlas, Community Edition, or Enterprise Advanced) to AI-powered developer tools like Codex, Claude, or any MCP-enabled agentic system. It brings context from MongoDB databases into developers’ environments, enabling data exploration, database operations, and context-aware code generation via natural language.

Additionally, the MongoDB MCP Server can serve as a building block for AI agents, giving them direct access to MongoDB databases for data retrieval and automated database operations.

The MongoDB MCP Server can be installed locally and self-managed or you can use the Atlas Managed MCP Server.

### How can I deploy the MongoDB MCP Server?

You can deploy the MongoDB MCP Server locally using stdio (for IDEs/agents like Claude Code or Cursor) or HTTP. It can also be self-hosted for broader access or packaged and deployed with Docker for easier containerized setups. In addition, for a fully hosted MCP Server, use the Atlas Managed MCP Server.

### Can an AI coding agent provision a database before you sign up for Atlas?

Yes. Atlas Ephemeral Clusters let an AI coding agent provision a free MongoDB Atlas M0 cluster in seconds, with no signup or login required. Use the returned connection string to start building against a live database, then claim the cluster into your Atlas account if you decide to keep developing.
