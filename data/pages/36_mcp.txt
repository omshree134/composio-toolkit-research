# Give your marketing agent the customer context it's missing

Generated by Klaviyo AI

The Klaviyo MCP server connects compatible AI agents to account data and tools for reporting, customer analysis, and campaign creation. The page explains supported clients, OAuth setup, access controls, and how the server differs from Composer, Klaviyo’s built-in AI marketing agent.

- Account context: Connected agents can use campaigns, flows, profiles, and orders to answer questions with Klaviyo account data.
- Analytics tools: An analytics tool built on Klaviyo Data Platform SQL, currently in beta, supports questions across data sets.
- Connection requirements: Owners, Admins, and Managers can authorize access through OAuth using clients such as Claude, ChatGPT, Cursor, and VS Code.
- Access controls: Custom connections support read-only mode; with write tools enabled, agents can create campaigns and update data, and each action should be reviewed.
- Composer distinction: Composer works inside Klaviyo, while the MCP server connects outside agents, with both drawing on the same data for analytics.

## What is the Klaviyo MCP server?

The Klaviyo MCP server is an authorized connection between your Klaviyo account and the AI agents your team uses. It runs on Model Context Protocol (MCP), an open standard for connecting AI models to data and tools, so a marketing agent can pull campaign results, compare flows, analyze customers, and create campaigns inside the access you approve.

## Why your marketing agent needs Klaviyo context

AI is moving into the tools marketers already have open. Gartner estimates that by 2028, one-third of user experiences will shift from native applications to agentic front ends. For a lot of growth marketers, that front end is already Claude or ChatGPT.

A marketing agent that can't see your account can only give you generic advice. Ask it which flow lost the most revenue last month, and it has nothing to check. Connect it to Klaviyo, and it answers from your campaigns, flows, profiles, and orders.

The goal hasn't changed: know your customers well enough that they come back. What's changed is which agent does the legwork.

## What your marketing agent can do with Klaviyo

Connected to Klaviyo, your marketing agent can answer the question and do the work in the same conversation.

| Goal | Ask your marketing agent | What it draws on |
| --- | --- | --- |
| Check campaign results | "How did our email campaigns perform over the last 30 days?" | Campaign reporting |
| Compare flows | "Rank our flows by conversions this quarter and show me the weakest 3." | Flow reporting |
| Understand repeat buying | "What percentage of customers have placed only one order?" | Klaviyo Data Platform SQL (beta) |
| Find top sellers | "What are my top 5 products by units sold in the last 90 days?" | Klaviyo Data Platform SQL (beta) |
| Build the next send | "Create an email campaign for our end-of-season sale." | Campaign tools (write access on) |

Try a bigger ask: "Review the last 90 days of campaign and flow performance and name the 3 changes worth making first." Your marketing agent pulls the numbers from Klaviyo, explains how it got them, and, with write tools on, drafts the first fix in your account for you to review.

For questions that cross data sets, like orders broken down by segment and country, the MCP server includes an analytics tool built on Klaviyo Data Platform SQL, which is in beta and available to all customers. Composer uses the same data, so a question asked in Claude and the same question asked in Klaviyo draw on one source. Before you act on a number, ask your marketing agent how it calculated it: it can show the data sets, dates, and filters behind the answer.

## How the Klaviyo MCP server works

MCP gives AI agents and software a shared way to talk. Klaviyo publishes one set of tools through MCP, and any compatible AI client can use them, so you don't need a custom integration for each agent your team tries.

The remote-hosted server is Klaviyo's recommended option. Your marketing agent connects through OAuth, where you sign in to Klaviyo and approve access, so there's no API key to paste into a chat. The server exposes more than 260 tools across campaigns, flows, profiles, segments, reporting, catalogs, and events.

| AI client | How it connects |
| --- | --- |
| Claude | The listed Klaviyo connector, or a custom connector |
| ChatGPT | The Klaviyo app, or a custom MCP server in developer mode |
| Cursor | The remote server URL in MCP settings |
| VS Code | The remote server URL in MCP configuration |
| Other MCP clients | Any client that supports remote servers, OAuth with dynamic client registration, and Streamable HTTP |

## How to control what your marketing agent can touch

Autonomous doesn't mean unsupervised. You decide how much your marketing agent can see and change when you set up the connection.

| Control | What it does |
| --- | --- |
| Role check | Only Owner, Admin, or Manager users can connect the remote server |
| OAuth approval | You review the requested permissions for your Klaviyo account and approve them |
| Read-only mode | Turns off tools that can change data in your account |
| Scoped tools | Limits the agent to tools within the API scopes you list, or to about 40 core tools |
| Content controls | Turns off tools that read user-generated content, like reviews and profile properties, that an AI model could mistake for instructions |
| Beta opt-in | Keeps new tools that may be unstable off until you turn them on |

The settings beyond role and OAuth work on custom connections. The listed Claude connector and the Klaviyo app for ChatGPT don't support them, so set up a custom connector when you want them. While write tools are on, review each action your agent takes.

A smart way to start: connect in read-only mode, use your marketing agent for reporting, and add write access once its answers hold up.

## How to connect your marketing agent in 5 steps

1. Confirm your role. Log in to the Klaviyo account you want to connect. You need an Owner, Admin, or Manager role.
2. Choose your client. For one account, use the listed Klaviyo connector in Claude or the Klaviyo app in ChatGPT. For several accounts or custom settings, set up a custom connection.
3. Add the server. For a custom connection, enter `https://mcp.klaviyo.com/mcp` with no trailing slash. Add any settings you want, such as `read-only=true`.
4. Approve access. Sign in with OAuth, review the requested permissions, and approve them.
5. Ask a first question. Try "How did my email campaigns perform last month?" If the Klaviyo tools don't respond, refresh your client's tool list.

Find instructions for each client in the Klaviyo MCP server setup guide.

## How MCP works with Composer

Klaviyo is the agent-first operating system for B2C, and MCP keeps it open to the AI tools you already use. The connection runs in two directions.

| Direction | What connects | What your marketing agent gets |
| --- | --- | --- |
| Out: the Klaviyo MCP server | Claude, ChatGPT, Cursor, and other AI clients connect to Klaviyo | Your campaigns, flows, customers, and analytics, plus tools to build in Klaviyo |
| In: MCP connectors in Composer | Tools like Notion, Asana, and Shopify connect to Composer | Briefs, calendars, and product data from outside Klaviyo, used in the work Composer prepares |

Composer, Klaviyo's AI marketing agent, works inside Klaviyo with your brand, your customer data, and your connected tools. Ask it to review your launch brief in Google Drive and your product data in Shopify, then build the campaign in Klaviyo. You can also add your own MCP connector with a URL and an optional token.

Humans set the goals and guardrails, and Composer has built-in control: nothing goes live without human approval.

Use Composer when you want a marketing agent built into Klaviyo, with previews and approvals in the app. Use the MCP server when your team already works in Claude, ChatGPT, or a code editor and wants Klaviyo there too. Analytics questions draw on the same data either way, so you don't have to pick one.

## Klaviyo MCP server FAQs

### What is the Klaviyo MCP server used for?

It connects AI clients like Claude, ChatGPT, and Cursor to your Klaviyo account, so a marketing agent can report on performance, analyze customers, and create campaigns from a chat. See the examples in "What your marketing agent can do with Klaviyo" above.

### Which AI clients work with the Klaviyo MCP server?

Klaviyo documents connections for Claude, ChatGPT, Cursor, and VS Code. Other MCP clients that support remote servers, OAuth with dynamic client registration, and Streamable HTTP can connect too.

### Who can connect the Klaviyo MCP server?

Users with an Owner, Admin, or Manager role in the Klaviyo account can connect the remote-hosted server.

### Can my marketing agent change things in my Klaviyo account?

Yes, if you allow it. With write tools on, it can create campaigns and update data. Add `read-only=true` to a custom connection to turn those tools off, and review each action while write tools are on.

### Is the Klaviyo MCP server the same as Composer?

No. Composer is Klaviyo's AI marketing agent and works inside Klaviyo. The MCP server lets outside agents work with your Klaviyo data, and analytics questions draw on the same data in both.

### Can agencies connect more than one Klaviyo account?

Yes. Add a separate custom connection for each client account, or follow the Klaviyo MCP server guide for agencies.
