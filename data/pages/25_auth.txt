# Pumble Integration API

## Introduction

 Welcome to the Pumble API. Built on REST principles, this API allows you to integrate Pumble into your own app, by using the endpoints below. If you're looking to integrate operations over users, channels, messages (list/preview, create new, update an existing one, leave reaction, reply etc.), you are in the right place. 

Detailed documentation is available here, explaining how to use the Node SDK to avoid boilerplate code and manual API calls. We strongly advise you to use our SDK, alternatively continue reading these docs if you prefer to integrate directly with our endpoints manually.

A prerequisite for using the integrations API is to set two headers (token and x-app-token) – in order to authenticate. You can follow this page to find out how to set it up.

## API endpoints usage

 All the endpoints (except auth) are prefixed with the API URL: https://api-ga.pumble.com/v1/. 

 For example, the endpoint to send a message looks as follows: https://api-ga.pumble.com/v1/channels/{channelId}/messages, where you'll replace ID in curly braces with your actual channel ID. 

## Authentication

To ensure the security of your data, all API requests must be authenticated.

- It's mandatory to include the token (access token issued to user/bot) and x-app-token (app token issued to your app, prefixed with 'xpat-') headers in every request, refer to API Client.
- Your credentials should only be visible to you and should NOT be shared publicly.
- By using this API, only operations within the scope of your workspace, user role and permissions are allowed.

## Rate limiter

 We enforce a rate limit on all API requests in order to maintain high availability and fair usage for all users. Default limitation is 100 requests per user per minute (per token header) and 500 per app (per x-app-token header). Exceeding this limit will result in error 429 - TOO_MANY_REQUESTS. 

Every 429 response includes a Retry-After header with the number of seconds to wait before retrying (e.g. Retry-After: 60).
