## Authentication

To start making calls to Brex APIs, generate a user token from your Brex dashboard and pass it along in your API call headers.

#### 1. Generate a user token

1. Sign in to dashboard.brex.com as an account admin or card admin.
2. Go to Developer > Settings.

- If your company has not accepted the developer API agreement, please review the terms and conditions. These must be accepted to use the developer API.

1. Click Create Token.
2. Create a name for your token that will help you identify it. Choose what level of data access you need for your application; these are the scopes your token will have.
![Create your token and choose your scopes](https://developer.brex.com/assets/auth-create-token.e7bc91ff162d118303d9032b8956d5c9aaa238b578c2b4af90abab72f0d72370.9c1bb791.png)
3. The next screen will confirm your previous selections. Make sure it looks good, then select Allow Access.
![Confirm your scopes](https://developer.brex.com/assets/auth-allow-access.ad0564cd0aa8c1799ae2780a96b26a77f71d80bd537ab29d4374faa55e264e3e.9c1bb791.png)
4. Your token is now created. Copy and store the token securely. You won't be able to see it again.
![Copy token](https://developer.brex.com/assets/auth-token.72c25266e0c54479d799b598dd248519bebd88cba6b2b355f7d7bfa95af53acc.9c1bb791.png)
5. Back on the developer page of your Brex dashboard, you should see your token listed now. As a security measure, part of the string is obfuscated. If you lose it, create a new one and replace the token.
![Developer dash](https://developer.brex.com/assets/auth-developer-dash.3b07510154850bb76961adb88a279aea5ce9830ff3a9ba65d77f11c7937f308c.9c1bb791.png)

Caution: Your user token is private and should not be shared. Never check it into version control or save it somewhere publicly accessible. If your user token is compromised or leaked, make sure to revoke it.

#### 2. Pass the user token in your API call headers

To pass your user token to Brex APIs, add it as a header to your API calls in the following format:

```
Authorization: "Bearer {{your user_token here}}"

```

If, for example, your user token value is `bxt_jBWQLZXtu1f4sVT6UjaWPp7Gh9nVGjzEZgRX`, your header will be:

```
Authorization: "Bearer bxt_jBWQLZXtu1f4sVT6UjaWPp7Gh9nVGjzEZgRX"

```

### Token revocation and expiration

There are two scenarios where tokens will be invalid for authentication:

- User tokens will expire if they are not used to make an API call for 90 days
- User tokens associated to users in a non-active status will no longer work

If your token is compromised, or you no longer need it, revoke the user token from the developer page in your Brex dashboard. Once revoked, any calls made with this token will immediately begin to fail.

## API Server

Brex currently only offers a production API server at `https://api.brex.com`. This is the base URL for all API calls.
