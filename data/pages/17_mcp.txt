# MCP server

> Connect Claude Code, Cursor, or any MCP client to your Plain workspace over the Model Context Protocol.

MCP (Model Context Protocol) is an open standard that lets AI tools connect to external platforms. The Plain MCP server at `https://mcp.plain.com/mcp` lets tools like Claude, ChatGPT, and Cursor work with your support data directly.

You authenticate with your existing Plain account, so the MCP server has the same permissions as your user. No API keys needed.

![MCP server in Plain](https://mintcdn.com/plain/esnLSCL6AbjPxXFS/public/images/mcp-server-1.png?fit=max&auto=format&n=esnLSCL6AbjPxXFS&q=85&s=39ebccf73a1794538e5573a64ade642d)

## Setup

### ChatGPT

In ChatGPT, add the official Plain plugin:

1. Open the Plain plugin and add it
2. Sign in with your Plain account and choose your workspace
3. In a chat, type @ and pick Plain

### Cursor

You can add the Plain MCP to Cursor via your Cursor config at `~/.cursor/mcp.json`

```json
{
  "mcpServers": {
    "plain": {
      "type": "remote",
      "url": "https://mcp.plain.com/mcp"
    }
  }
}

```

Go to Cursor Settings → Tools & MCP and click Connect next to Plain to authenticate.

### Claude.ai

1. Go to "Customize" → "Connectors"
2. Click the ➕ icon, then choose "Add custom connector"
3. Add a custom connector named "Plain" with the Remote MCP server URL `https://mcp.plain.com/mcp`
4. Click the "Connect" button next to the newly created Plain connector to authenticate.

![Claude.ai in Plain](https://mintcdn.com/plain/esnLSCL6AbjPxXFS/public/images/mcp-server-3.png?fit=max&auto=format&n=esnLSCL6AbjPxXFS&q=85&s=37b8d1a0b1d71c8740d7aea06b7c4d4d)

If you're on a Claude Team plan, you may need to reach out to your administrator to add this custom connector for you.

### Claude Code

Adding the Plain MCP to claude-code can be done via the `mcp-remote` helper package which involves adding the following to your `~/.claude.json` configuration.

```json
"mcpServers": {
  "plain": {
    "command": "npx",
    "args": ["-y", "mcp-remote", "https://mcp.plain.com/mcp"],
    "enabled": true
  }
}

```

Unfortunately Claude Code does not support refreshing OAuth tokens yet. A workaround until that is implemented is to use the `mcp-remote` npm package.

Next time you start Claude Code, it will launch a browser window asking you to authenticate with your Plain account and select the workspace you'd like to connect. Run the `/mcp` command and select the `plain` MCP to see more details.

### FX

fx is a terminal AI coding agent from Vercel Labs. Add the Plain MCP via the CLI:

```text
fx mcp add --transport http plain https://mcp.plain.com/mcp

```

Or add it manually to `~/.fx/mcp.json`:

```text
{
  "mcp": {
    "plain": {
      "type": "http",
      "url": "https://mcp.plain.com/mcp",
      "enabled": true
    }
  }
}

```

fx will prompt you to complete the OAuth flow with your Plain account on the next session start.

### Other MCP clients

MCP clients that run locally (not in the browser) can connect to Plain if they support remote HTTP servers. Point it at `https://mcp.plain.com/mcp` and complete the OAuth flow when prompted.

## Authentication

Plain MCP uses OAuth to allow your MCP server connection to share the same context as your normal web app user. No additional managing of permissions required. This means replies to threads will appear as though they come from your user.

### Required OAuth scopes

The Plain MCP server requires every OAuth token to include the `openid` and `offline_access` scopes. If your authorization request omits these, the server returns `403 Forbidden` , even when OAuth completes successfully and returns tokens.

Set `scope` to `openid offline_access` (space-separated) in your authorization request. If you are using `@modelcontextprotocol/sdk`, some versions discover required scopes automatically via the Protected Resource Metadata endpoint. If yours does not, set them explicitly in your client configuration.

After you sign in, your client receives an access token and a refresh token; automatic refresh depends on your client.

## Available tools

Once connected, your AI client can do almost anything you can do in Plain, across nearly 400 tools.

Tools cover:

- Threads and replies
- Customers and accounts
- Labels, thread fields, and tasks
- The Help Center and knowledge sources
- Workflows and broadcasts
- Tiers, service level agreements (SLAs), and business hours
- Snippets and saved views
- Discussions with the Sidekick Agent

### Good to know

- Your AI client can ask you to confirm actions such as sending a reply or deleting data.
- Your Plain role and permissions apply to every tool.
- Some changes stay in the Plain app: API keys, billing, roles, invites, webhooks, and custom domains.
- The tool list can change. Reconnect the server if a tool is missing.

## Interactive views in your chat

Some AI clients can show parts of Plain right inside the chat, so you can review and change what your AI client set up without opening Plain. These views are built on MCP Apps, an official extension to MCP. They act as your user, with your role and permissions, like every other tool.

Your AI client opens a view by calling one of the tools below. AI clients call these tools when they're relevant, for example after creating a workflow or when a specific thread comes up. You can also ask for one directly: "Show me my labels."

### Thread

`showThread` shows a thread as Plain's thread page. You can read the thread's messages, reply, add notes, and change the thread's status, assignee, priority, labels and fields. The view doesn't update live; it refreshes every 15s while it's on screen.

![The Thread view in a Claude chat, showing a test thread's timeline and reply bar](https://mintcdn.com/plain/GOsEKYocdnM2CjQv/public/images/mcp-server-4.png?fit=max&auto=format&n=GOsEKYocdnM2CjQv&q=85&s=c285c33b2675d6ec2fcab5600528dc23)

### Workflow editor

`showWorkflow` opens a workflow in Plain's workflow editor, so you can review and change a workflow your AI client built or changed.

![The workflow editor view in a Claude chat, showing the AI labels triage workflow](https://mintcdn.com/plain/GOsEKYocdnM2CjQv/public/images/mcp-server-5.png?fit=max&auto=format&n=GOsEKYocdnM2CjQv&q=85&s=fec41c9dab5df0eb85e52d6d01007168)

### Labels

`showLabels` shows your workspace's labels, which you can create and edit in place. Your AI client can pass labels it recommends as suggestions, and you create the ones you want by clicking them. The call itself creates nothing.

![The Labels view in a Claude chat, with three suggested labels above the workspace's active labels](https://mintcdn.com/plain/GOsEKYocdnM2CjQv/public/images/mcp-server-6.png?fit=max&auto=format&n=GOsEKYocdnM2CjQv&q=85&s=bbcda9d6e9bc949773e89c40f79c2d42)

### Which clients show views

Views appear in clients that support the MCP Apps extension, for example Claude.ai, Claude Desktop and ChatGPT. For the current list, see the MCP extension support matrix.

In clients without MCP Apps support, the view tools aren't listed. Every other tool works as usual and returns text, so there's nothing to set up.

## Use case examples

### Triage your queue

> "Show me my assigned threads. Summarize the top 5 by urgency and suggest which ones I should handle first."

Read your active threads and get a prioritized summary without opening each one.

### Understand a customer's history

> "Look up the customer with email alex@acme.com. Show me their recent threads and summarize the pattern. Are they hitting the same issue repeatedly?"

Pull together a customer's full context in seconds instead of clicking through timelines.

### Summarize what's waiting

> "Show me all my TODO threads. Group them by label and summarize what each one is about."

See what has gone quiet, so you can decide what needs attention.

### Draft a reply with full context

> "Show me thread th_01ABC123. Read the full timeline, then draft a reply that addresses the customer's latest question. Use a helpful but concise tone."

The AI reads the full thread history and drafts a reply for you to review before sending.

### Audit your Help Center

> "List all articles in my Help Center. Flag any that haven't been updated in the last 90 days."

Spot outdated documentation without manually checking each article.

### Fill a knowledge gap

> "Show me the knowledge gaps customers hit this week. For the top one, check whether our knowledge sources already cover it, draft a Help Center article, and mark the gap's task done."

Turn a question the Customer Agent couldn't answer into an article without leaving your AI client.

### Get a snapshot of an account's health

> "Look up the account 'Acme Corp'. Show me their details and all open threads. Are there any patterns or escalation risks?"

Prep for an account review by pulling account context and open issues together.

### Cross-reference with other tools

The Plain MCP works alongside other MCP servers. If you also have Slack, GitHub, or Linear MCPs connected, you can combine them:

> "Find threads about 'payment errors' from the last 7 days, check if there's a related GitHub issue, and post a summary to #incidents in Slack."

Each server handles its own domain, and the AI coordinates between them.

## If something isn't working

- Can't authenticate: Make sure you can log into Plain at app.plain.com first. The MCP server uses the same auth.
- 403 after OAuth completes: Your token is missing required scopes. Add `openid offline_access` to the `scope` parameter in your authorization request and complete a fresh OAuth flow. See Authentication for details.
- Tool not appearing: Some AI clients cache available tools. Try disconnecting and reconnecting the MCP server.
- View not appearing: Check that your client supports MCP Apps (see Which clients show views). If it does, disconnect and reconnect the Plain MCP server, then start a new chat.
- Permission errors: Check that your Plain user has the right role for the action you're trying to take.

If it's still not working, collect:

- Your workspace ID (visible in Settings → General)
- The exact error message
- Which AI client you're using

Then reach out to us via help@plain.com for assistance.
