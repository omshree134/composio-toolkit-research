 Model Context Protocol (MCP)

The Gemini Notebook API provides a remote Model Context Protocol (MCP) server at `https://notebook.googleapis.com/mcp`. Connecting an MCP-compatible agent or IDE to this endpoint exposes tools for creating notebooks and ingesting sources over Streamable HTTP (JSON-RPC 2.0).

## Endpoint and authentication Copy link to this section: Endpoint and authentication

| Setting | Value |
| --- | --- |
| Server URL | `https://notebook.googleapis.com/mcp` |
| Transport | Streamable HTTP (`POST` with `Content-Type: application/json`) |
| OAuth 2.0 scope | `https://www.googleapis.com/auth/notebook` |
| Headers | `Authorization: Bearer ACCESS_TOKEN` `x-goog-user-project: PROJECT_ID` (required when using Application Default Credentials) |

Enable the API in your Google Cloud project and generate an access token with the `notebook` scope before configuring your client:

```
export PROJECT_ID="YOUR_PROJECT_ID"

gcloud services enable notebook.googleapis.com --project="$PROJECT_ID"

gcloud auth application-default login \
  --scopes="https://www.googleapis.com/auth/cloud-platform,https://www.googleapis.com/auth/notebook"

export ACCESS_TOKEN=$(gcloud auth application-default print-access-token)

```

See Authentication for details on OAuth 2.0 scopes, personal Google Account requirements, and one-time Gemini Notebook sign-in prerequisites.

## Configure an MCP client

Add the remote HTTP MCP server using the `claude mcp add` command:

```
claude mcp add gemini-notebook-api \
  --transport http https://notebook.googleapis.com/mcp \
  --header "Authorization: Bearer $ACCESS_TOKEN" \
  --header "x-goog-user-project: $PROJECT_ID"

```

Add the server to `.cursor/mcp.json` in your project root (or `~/.cursor/mcp.json` globally):

```
{
  "mcpServers": {
    "gemini-notebook-api": {
      "url": "https://notebook.googleapis.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_ACCESS_TOKEN",
        "x-goog-user-project": "YOUR_PROJECT_ID"
      }
    }
  }
}

```

For any MCP client that supports remote Streamable HTTP servers, configure the endpoint URL and headers:

```
{
  "mcpServers": {
    "gemini-notebook-api": {
      "url": "https://notebook.googleapis.com/mcp",
      "headers": {
        "Authorization": "Bearer YOUR_ACCESS_TOKEN",
        "x-goog-user-project": "YOUR_PROJECT_ID"
      }
    }
  }
}

```

Note: Access tokens minted using `gcloud auth application-default
print-access-token` expire after one hour. Refresh the token when it expires.

## Available MCP tools

The MCP server exposes 7 tools corresponding to the REST API methods:

| Tool name | Description | Required arguments | Optional arguments |
| --- | --- | --- | --- |
| `create_notebook` | Creates a new notebook. | `notebook` (`{"displayName": "..."}`) | — |
| `get_notebook` | Gets metadata for a notebook. | `name` (`notebooks/{notebook}`) | — |
| `list_notebooks` | Lists notebooks accessible to the caller. | — | `pageSize`, `pageToken`, `filter` (`notebook.is_owner = true` or `notebook.is_owner = false`) |
| `update_notebook` | Updates a notebook's display name. | `notebook` (`{"name": "notebooks/{notebook}", "displayName": "..."}`) | `updateMask` (`displayName`) |
| `create_source` | Ingests a web URL, YouTube video, plain text, or Markdown source into a notebook. | `parent` (`notebooks/{notebook}`), `source` (`{"displayName": "...", "webContent": {"url": "..."}}` or `{"displayName": "...", "mimeType": "text/markdown", "textContent": {"content": "..."}}`) | — |
| `get_source` | Gets metadata and processing state (`PROCESSING`, `ACTIVE`, `FAILED`) for a source. | `name` (`notebooks/{notebook}/sources/{source}`) | — |
| `list_sources` | Lists all sources in a notebook. | `parent` (`notebooks/{notebook}`) | `pageSize`, `pageToken` |

Note: File uploads aren't available as an MCP tool. To upload a file, call the REST `UploadSource` endpoint.

"MCP-Protocol-Version:
