# Server API list

Server-side APIs can help you access and modify data in the Lark system. For how to call server-side APIs, please read: How to call server-side APIs

- Unlimited: Core features including Authentication and Authorization, Event Subscription, and Contacts are free to use, regardless of your Lark plan.
- Basic: This covers most Lark features. Usage is tallied, and heavy users may need to consider a higher-tier Lark plan to avoid restrictions.
- Advanced: Pricing for these APIs is usage-based. To access them, you'll need to buy a dedicated quota package.
- For all the details, read Policy Update: Adjusting API Call Limits for Custom Apps.
